# Roadmap

What comes after v0.1, from [spec.md](spec.md) §19. None of it is planned for a date; each item
becomes an issue labeled `idea` when someone starts on it, and v0.1's principles (lightweight,
necessary only, zero JavaScript by default) still apply.

- Search (Pagefind).
- PDF export.
- DOI helpers: Crossref deposit XML from front matter; Zenodo and DataCite metadata.
- A full peer-review workflow: issue templates, pull request previews, a review checklist action.
- Comments (giscus).
- Jupyter notebook import.
- More citation styles (CSL), and narrative citations (`@key` → "Lovelace et al. (2026)").
- Clickable equation terms (KaTeX `\htmlClass`, MathJax `\class`) with definitions.
- Auto-generated social images.
- JSON-LD `ScholarlyArticle`.
- A Markdown or plain-text version of each article for readers and agents.
- Articles from separate repositories; guidance and tooling for large data.
- Shared author profiles and author pages.
- Translations (i18n).
- The markdown pipeline on Sätteri plugins, once they cover math and Elucidate's needs.
- `elucidate eject <Component>`, to copy a structural component for overriding.
- A "Use this template" mirror repository for the starter.
